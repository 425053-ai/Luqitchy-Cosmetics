## 🔑 Critical Security Items (Before Launch!)

### 🔴 MUST DO #1: Change Admin Password
**Current (Bad):** `admin123` ❌
**Change To:** `Your_Strong_Password_2026!` ✅
**File:** `.env.local`

### 🔴 MUST DO #2: Create Firestore Counter
**Location:** Collections → counters → orders (value: 0)
**Why:** Orders won't save without this

### 🔴 MUST DO #3: Update Security Rules
**Go To:** Firebase Console → Firestore → Rules
**Change:** `allow read: if true` → Authenticated only
